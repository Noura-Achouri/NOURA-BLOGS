# NOURA-BLOGS ✦

My personal technical blog about software engineering, Linux, AI, and cybersecurity.

## Preview

Open `index.html` in a browser — no build step, no dependencies.

```
# or serve it locally
python -m http.server 8000
# then visit http://localhost:8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure (nav, hero, about, articles, topics, contact, footer) |
| `styles.css` | Design system: tokens, light/dark themes, responsive layout |
| `script.js` | Theme toggle, mobile menu, scroll reveal, active-link spy, form validation |

## Features

- Light / dark mode with your choice saved in `localStorage`
- Sticky blurred navbar that highlights the section you're reading
- Animated gradient hero with a terminal-style intro card
- Article cards with hover lift, tags and read time
- Scroll-reveal animations (disabled automatically for reduced-motion users)
- Fully responsive: desktop, tablet and mobile
